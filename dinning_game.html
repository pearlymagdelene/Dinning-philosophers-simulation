THE RULEBOOK

Behind the spellwork

Threads & processes

Each wizard acts as a concurrent thread, moving between thinking and requesting shared resources.

Critical section

Casting is the critical section. A wizard enters only after securing both neighboring chopsticks.

Mutual exclusion

Each chopstick has a single owner, so two neighboring wizards cannot claim it simultaneously.

Synchronization

The scheduler coordinates requests and releases so independent threads share resources safely.

Resource allocation

The roster and table show who owns each resource and which requests are currently blocked.

Deadlock & starvation

Deadlock is a circular wait with no progress. Starvation is prolonged waiting while others continue.

Prevention spells

Resource ordering removes circular wait. Limiting contenders to N - 1 prevents everyone holding one resource at once.
