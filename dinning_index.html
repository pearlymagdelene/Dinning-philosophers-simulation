OPERATING SYSTEMS

What the table demonstrates

Processes and threads

Each philosopher models a concurrent thread that alternates between doing work and requesting shared resources.

Critical section

Eating is the critical section. A philosopher enters it only after acquiring both neighboring forks.

Mutual exclusion

A chopstick has one owner at a time, so neighboring philosophers cannot use the same resource simultaneously.

Synchronization

The scheduler coordinates fork acquisition and release so independent threads share resources safely.

Resource allocation

The chopsticks are resources; the table shows which thread owns each one and which requests are blocked.

Deadlock and starvation

Deadlock is a circular wait with no progress. Starvation is prolonged waiting while other threads keep progressing.

Deadlock prevention

Global resource ordering removes circular wait. Limiting contenders to N - 1 prevents every philosopher holding one chopstick at once.
